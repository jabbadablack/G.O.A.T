# v0.1 – Pre-Alpha

> **Release Date:** 2026-08-26  
> **Status:** Pre-Alpha  
> **Engine:** O3DE

---

## 🎉 Initial Release

This is the first public release of G.O.A.T. It provides a complete, production-ready AI framework for O3DE with a backend-driven architecture.

---

## ✅ New Features

### Core Engine

- **Backend Abstraction:** Unified planning interface (`IBackend`) supporting Behavior Trees, Direct actions, and Lua-defined planners.
- **Behavior Tree Engine:** Iterative `TreeWalker` with flat, cache-friendly `DecisionProgram`s.
- **Blackboard System:** Schema-driven, type-safe blackboard with Global, Agent, and Squad scopes.
- **Lua Authoring DSL:** Full Lua vocabulary for `tree`, `behavior`, `flow`, and `backend` definitions.
- **Agent Scheduling:** Four pacing bands (`BandCount = 4`) using `AZ::ScheduledEvent`.
- **Event-Driven Guards:** `GuardWatch` watches only relevant blackboard keys, enabling zero-polling condition evaluation.
- **Object Management:** `AgentStore` for dense, generation-checked storage.

### Components

- **GOATAgentComponent:** Turns any entity into an AI agent.
- **GOATSystemComponent:** "God object" that owns all services and implements `IAgentSystem`.
- **LuaBackend:** Bridges C++ to Lua-defined planning backends.
- **RunScriptAction & WaitAction:** Core action verbs.

### Asset System

- **BlackboardAsset (.bbx):** Declares blackboard variables in the Asset Editor.
- **BehaviorTreeAsset (.bt):** Authored tree format for a future graph editor.

---

## 🛠️ Known Limitations

- **Navigation Library:** Not yet implemented (planned for future).
- **Bark System:** Not yet implemented (planned for future).
- **Perception Module:** Not yet implemented (planned for future).
- **Graph Editor:** Trees are authored in Lua; no visual editor yet.
